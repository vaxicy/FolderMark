## 修复俄语 locale 格式导致的大量 undefined/空白标签
- 问题：切换俄语后搜索框 placeholder 显示 `undefined`，多处标签空白。根因是 `_locales/ru/messages.json` 值被写成普通字符串 `"key": "value"`，而 `src/utils/i18n.js` 的 `getMessage` 按 Chrome i18n 标准格式读取 `message.message`，字符串的 `.message` 为 `undefined`。
- 修复：把俄语 locale 全部 280 个 key 的值包装成 `{ "message": "..." }` 对象格式。
- 验证：6 locale 均 object 格式 + 280 key 对齐；`node --check popup.js` 通过。
- 经验：新增 locale 文件后必须检查值类型是否为 `{message:string}`，不能是扁平字符串。
- Chrome 扩展项目不主动 push，等用户指令。
